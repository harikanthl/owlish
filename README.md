# Owlish for Mac

Release downloads for **Owlish**, a study app for Mac, iPhone and iPad: turn videos, papers,
articles and lectures into study packs with notes, flashcards, quizzes and a tutor.

- **Download:** [latest Owlish.dmg](https://github.com/harikanthl/owlish/releases/latest/download/Owlish.dmg)
  (notarized by Apple, macOS 15.5 or later)
- **Website:** https://owlish.site
- **Support:** https://owlish.site/support
- **Privacy:** https://owlish.site/privacy

The app updates itself through Sparkle from the feed at `owlish.site/appcast.xml`.
This repository only hosts the release files.
